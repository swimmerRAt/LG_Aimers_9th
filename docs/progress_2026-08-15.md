## 핵심 결과

| 모델 | 2022 Brier / 점수 | 2023 Brier / 점수 | 2024 Brier / 점수 | 3-split 평균 Brier |
|---|---:|---:|---:|---:|
| Constant | 0.249366 / 0 | 0.251567 / 0 | 0.251875 / 0 | 0.250936 |
| RandomForest | 0.243990 / 2076.21 | 0.251661 / 0 | 0.248767 / 416.18 | **0.248139** |
| HistGB | 0.243671 / 2204.35 | 0.253600 / 0 | **0.248366 / 576.62** | 0.248546 |

- 다중 split 평균은 RandomForest, 가장 최근 2024는 HistGB가 우세하다.
- 2023에는 두 모델 모두 상수보다 나빠 모델 안정성이 확보되지 않았다.
- RF 85% + HistGB 15% OOF 평균은 Brier를 약 0.00001만 개선해 채택하지 않았다.
- 2023·2024 예측 평균이 실제보다 높아 시간에 따른 확률 수준 보정이 1순위다.
