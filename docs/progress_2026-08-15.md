## 완료한 작업

### 데이터와 검증

- 평가 서버와 동일한 Python 3.11.15 기반 `.venv` 구축
- `train.csv` 1,475,092행과 `trackman_history.csv` 1,793,078행 품질 검사
- 2022·2023·2024 시즌 forward validation과 OOF 저장 구현
- 테스트 행끼리 계산한 빈도·rolling·target encoding을 사용하지 않도록 누수 검사 적용
- Trackman 선수 ID는 검증 가능한 공식 매핑이 없어 최종 모델에서 제외
- Brier Score와 대회 정규화 점수, paired Brier 95% 신뢰구간 구현

### 모델 실험

- Constant, LogisticRegression, RandomForest, HistGradientBoosting 기준선 비교
- HistGB 45% + ExtraTrees 55% 기본 앙상블 구축
- Optuna 단일 시즌 탐색과 다중 시즌 robust objective + 2024 one-shot outer 검증 구현
- CatBoost와 TabM 비교 실험 후 최종 코드 경로에서 제거
- XGBoost 비교 코드는 보존하되 최종 모델에서는 제외
- 전체·최근 3년·최근 2년·시간가중 학습 구간 비교
- 시간창 앙상블 비중을 5% 격자가 아닌 SLSQP 연속 최적화로 선택
- 선수 성공률 smoothing `λ=50, 200, 500, 1000` 비교
- `game_type`별 최근 오차 보정과 Rolling OOF 전체 확률 보정 구현
- 현재 최종 후보를 2019~2024년 전체 데이터로 재학습하고 저장

### 제출과 재현성

- `script.py`의 입력 스키마, 확률 범위, ID 정렬, NaN·무한대 검사 구현
- `output/submission.csv`와 피처 중요도 CSV·SVG 동시 생성
- 최소 제출 ZIP 빌더 및 ZIP 무결성 검사 구현
- Git에서 대용량 OOF, 캐시, 모델, 제출 ZIP을 제외하도록 `.gitignore` 구성
- 전체 단위·회귀 테스트 **27개 통과**

## 주요 성능 변화

다음 점수는 모두 2019~2023년으로 학습하고 2024년을 예측하는 동일한 forward validation
기준이다. 공식 리더보드 점수와는 평가 데이터가 달라 직접 같은 값으로 볼 수 없다.

| 모델 또는 실험 | 2024 Brier | 예상 점수 | 현재 모델 대비 |
|---|---:|---:|---:|
| HistGB 기준선 | 0.24836650 | 576.61745 | -146.71697 |
| HistGB 45% + ExtraTrees 55% | 0.24805763 | 700.25764 | -23.07678 |
| XGBoost depth 6 | 0.24818884 | 647.73609 | -75.59833 |
| Robust Optuna 후보 | 0.24857074 | 494.85698 | -228.47744 |
| 원본 시간창 앙상블 | 0.24805506 | 701.28755 | -22.04687 |
| smoothing 시간창 앙상블 | 0.24808941 | 687.53616 | -35.79826 |
| smoothing + 두 후단 보정 | 0.24805249 | 702.31513 | -21.01929 |
| **시간창 앙상블 + 두 후단 보정** | **0.24799999** | **723.33442** | **기준** |

현재 모델은 원본 시간창 앙상블보다 Brier가 `0.00005507` 낮고 예상 점수가 약
`22.04687점` 높다. paired Brier 차이의 95% 신뢰구간은
`[-0.00007272, -0.00003743]`으로 개선 방향이다.

다만 2024 검증 시즌은 모델 개발 과정에서 여러 번 확인했으므로 완전히 새로운 one-shot
outer holdout은 아니다. `723.33442점`은 현재 로컬 기준점이며 실제 일반화 성능은 신규 시즌
또는 리더보드 제출로 다시 확인해야 한다.
